# Créer un compte AnkiWeb

**Durée :** environ 5 minutes  
**À prévoir :** une adresse e-mail à laquelle vous avez accès.

## 1. Ouvrir la page d’inscription

Dans votre navigateur, rendez-vous sur la page officielle d’inscription :

<https://ankiweb.net/account/register>

Vous pouvez aussi ouvrir la page d’accueil d’AnkiWeb, puis choisir l’option d’inscription :

<https://ankiweb.net/>

**Copie d’écran à réaliser :** la page d’inscription, avant de remplir les champs.  
**Adresse de la page :** <https://ankiweb.net/account/register>

## 2. Saisir votre adresse e-mail et un mot de passe

Remplissez les champs demandés sur la page, puis envoyez le formulaire.

Choisissez un mot de passe que vous pourrez retrouver facilement et vérifiez que l’adresse e-mail saisie est correcte.

**Copie d’écran à réaliser :** le formulaire d’inscription.  
Par prudence, masquez votre adresse e-mail et ne montrez jamais votre mot de passe.

## 3. Confirmer votre adresse e-mail

AnkiWeb peut vous demander de confirmer votre inscription à partir d’un message envoyé à votre adresse e-mail. Ouvrez ce message et suivez les instructions qu’il contient. Si vous ne le trouvez pas, vérifiez le dossier des courriers indésirables.

**Copie d’écran à réaliser :** la page indiquant qu’un e-mail de confirmation a été envoyé, ou le message de confirmation.  
Masquez les informations personnelles avant de partager la capture.

## 4. Se connecter à AnkiWeb

Une fois l’inscription terminée, ouvrez la page de connexion :

<https://ankiweb.net/account/login>

Saisissez l’adresse e-mail et le mot de passe associés à votre compte.

**Copie d’écran à réaliser :** la page de connexion, sans afficher vos identifiants.

## 5. Synchroniser Anki avec AnkiWeb (facultatif)

Pour synchroniser vos cartes entre Anki et AnkiWeb, ouvrez l’application Anki sur votre appareil et utilisez le bouton **Synchroniser**. Connectez-vous avec votre compte lorsque l’application le demande.

**Copie d’écran à réaliser :** le bouton de synchronisation dans Anki ou la fenêtre de connexion.  
L’apparence peut varier selon la version et l’appareil utilisés.

# Télécharger et installer Anki sur ordinateur et téléphone

Anki propose une application pour ordinateur, ainsi que des applications mobiles. Les versions mobiles officielles s’appellent **AnkiDroid** sur Android et **AnkiMobile Flashcards** sur iPhone et iPad.

> **À noter :** Anki pour ordinateur et AnkiDroid pour Android sont gratuits. AnkiMobile pour iOS est une application payante ; son prix est affiché dans l’App Store (≈ 30 €).

## 1. Sur PC Windows

1. Ouvrez la page officielle de téléchargement :   <https://apps.ankiweb.net/>
   ![[Pasted image 20261030164120.png|669]]

2. Dans la section des téléchargements pour ordinateur, sélectionnez la version Windows correspondant à votre appareil.
   - Pour la plupart des PC Intel ou AMD, choisissez **Windows 10+ (x64)**.
   - Choisissez **Windows 11 (ARM)** uniquement si votre PC utilise un processeur ARM.
   ![[Download anki.png|952]]
3. Ouvrez le fichier téléchargé et suivez les instructions de l’installateur.
4. Lancez Anki depuis le menu Démarrer.

## 2. Sur Mac

1. Ouvrez la page officielle : <https://apps.ankiweb.net/>
   ![[Pasted image 20261030164120.png|669]]
2. Choisissez la version macOS correspondant au processeur de votre Mac :
   - **Apple Silicon** pour les Mac équipés d’une puce Apple de série M ;
   - **Intel** pour les anciens Mac équipés d’un processeur Intel.
![[Pasted image 20261030170431.png|791]]
3. Ouvrez le fichier téléchargé.
4. Suivez les indications à l’écran pour installer Anki, puis ouvrez l’application depuis le dossier **Applications**.

## 3. Sur Android

1. Ouvrez Google Play sur votre appareil, ou rendez-vous sur la page de l’application : <https://play.google.com/store/apps/details?id=com.ichi2.anki>
![[Pasted image 20261030170829.png|850]]
2. Vérifiez le nom **AnkiDroid Flashcards** et l’éditeur **AnkiDroid Open Source Team**.
3. Touchez **Installer**.
4. Une fois l’installation terminée, ouvrez AnkiDroid.

## 4. Sur iPhone ou iPad (iOS)

1. Ouvrez l’App Store sur votre appareil.
2. Recherchez **AnkiMobile Flashcards**.
3. Vérifiez que vous avez sélectionné l’application officielle AnkiMobile, puis consultez son prix affiché dans votre App Store.
   ![[Pasted image 20261030171027.png|743]]
4. Touchez le bouton d’achat et confirmez selon les instructions de votre appareil.
5. Ouvrez l’application après son installation.

Vous pouvez également accéder à l’application depuis la page officielle d’Anki, dans la section consacrée aux applications mobiles :
![[Anki - powerful, intelligent flashcards.png|253]]

## 5. Synchroniser vos appareils avec AnkiWeb

Synchroniser vos cartes entre vos appareils :

1. Ouvrez Anki ou l’application mobile.
2. Touchez ou cliquez sur **Synchroniser**.
3. Connectez-vous avec votre compte AnkiWeb lorsque l’application le demande.

La synchronisation permet de retrouver votre collection sur plusieurs appareils après l’envoi des changements.
